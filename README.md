# Espiga Blanca Website

Sitio web estático para Espiga Blanca.

## Archivos

- index.html
- style.css
- script.js
- assets/

## Antes de publicar

1. Cambiar el número de WhatsApp en `script.js`.
2. Cambiar dirección, horarios y redes en `index.html`.
3. Reemplazar SVGs por fotos reales cuando estén disponibles.
4. Agregar datos nutrimentales solo cuando estén validados.
